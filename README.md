# Trekking-Management-App-MAD-2
TrekkingMate V2 is a web application for managing trekking activities. It enables admins to manage treks, staff, users, and bookings, while staff manage assigned treks and trekkers book trips and track their history. It uses Flask, VueJS, Bootstrap, SQLite, Redis, and Celery to manage bookings, prevent overbooking, and automate reminder and reports
